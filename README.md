# Mokotahi

A minimal, interactive website with Bayer dithering shader effects.

## Features

- Interactive Bayer dithering background (click to create ripple effects)
- WebGL shader-based animation using Three.js
- Responsive design
- Minimalist aesthetic

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

The site automatically deploys to GitHub Pages when you push to the `main` branch.
